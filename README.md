# British Grammar School Website

A modern responsive school website built for British Grammar School, Secunderabad, featuring a custom-coded UI, interactive hero slider, responsive mobile navigation, admissions section, and a dedicated One Kynd Montessori landing page.

## Features

- Fully responsive design
- Interactive hero slider
- Mobile hamburger navigation
- Smooth scrolling navigation
- Dedicated Montessori landing page
- Custom-coded sections
- Modern UI/UX
- SEO-friendly structure
- GitHub + Vercel deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Vercel Deployment

## Pages

- Main School Website
- One Kynd Montessori Page
